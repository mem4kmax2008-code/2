## Структура БД

### Таблица `students`

```sql
CREATE TABLE students (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    first_name TEXT NOT NULL,
    last_name TEXT NOT NULL,
    birth_date DATE,
    group_name TEXT,
    average_grade REAL
)
```

**Поля:**
- `id` - уникальный идентификатор (автоинк��емент)
- `first_name` - имя студента (обязательно)
- `last_name` - фамилия студента (обязательно)
- `birth_date` - дата рождения (формат YYYY-MM-DD)
- `group_name` - название группы
- `average_grade` - средняя оценка (от 0 до 5)

## Функциональность

### Навигация
- **⏮ Первая** - перейти на первую запись
- **◀ Предыдущая** - перейти на предыдущую запись
- **Следующая ▶** - перейти на следующую запись
- **Последняя ⏭** - перейти на последнюю запись

### Управление данными
- **➕ Новая запись** - очистить поля для добавления новой записи
- **💾 Сохранить** - сохранить данные (INSERT или UPDATE)
- **🗑️ Удалить** - удалить текущую запись
- **🔄 Обновить** - перезагрузить данные из БД

### Поля ввода
- **ID** - автоматический номер (только для чтения)
- **Имя** - имя студента
- **Фамилия** - фамилия студента
- **Дата рождения** - в формате YYYY-MM-DD
- **Группа** - название группы
- **Средняя оценка** - число от 0 до 5
